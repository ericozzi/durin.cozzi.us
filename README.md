# Durin's website

A small Hugo site for Durin. Contact and identification details are configured in `hugo.toml`.

Run locally with `hugo server`, or build the static site with `hugo`. The generated site is written to `public/`.

Pushes to `main` build and deploy the site with GitHub Actions. In the repository's Pages settings, set the source to **GitHub Actions** and configure `durin.cozzi.us` as the custom domain.
